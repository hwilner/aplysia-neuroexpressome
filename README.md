# aplysia-neuroexpressome

Project repository. The full specification, the delivery contract, the gates and
the pre-registration live in
[`aplysia-research-programme`](https://github.com/hwilner/aplysia-research-programme).

- Contract: `aplysia-research-programme/project-contracts/`
- Deviations: logged as `deviation-log` issues, never as silent edits
- Gate decisions: `gate-decision` issues
- Released data: Zenodo DOI, not committed here

This repository is bootstrapped empty on purpose. The pre-registration is
committed before any analysis exists; the commit timestamp is the evidence.
